## 1. 需要什麼

- Windows 11 x64（繁體中文版，NFR-01）
- 一個有系統管理員權限的帳號。工具啟動時會跳出 UAC，按「否」工具不會啟動（FR-02）
- 不需要安裝 Python 或其他套件（NFR-02）
- 「下載」資料夾所在的磁碟要有足夠的空間，見第 4 節

## 2. 目錄結構

```
D:\Helper\                        ← 任何位置都可以，見第 3 節的權限設定
├─ helper.exe
└─ helper_software\               ← 資源資料夾
   ├─ software.xml                軟體清單
   ├─ software.xsd                給編輯器檢查格式用（選用）
   ├─ system_tasks.xml            系統設定任務清單（選用：沒有的話，系統設定分頁停用）
   ├─ system_tasks.xsd
   ├─ helper_icon.ico             視窗圖示（選用；沒有時使用 3.0.1 以前的 hpler_icon.ico）
   ├─ tasks\                      每個任務一個 .cmd，檔名是任務的 id
   └─ 3DMark\ …                   各軟體的子資料夾
```

- 資源資料夾也可以叫 `Helper\`（2.0 的名稱，3.0 再保留一個版本，FR-22）。兩個都存在時，使用 `helper_software\`。
- `software.xml` 和 `helper.exe` 放在同一層也可以（和 2.0 的舊佈局相同，DD8）。
- 工具一律以 `helper.exe` 的位置找資源資料夾，從捷徑或其他資料夾啟動，結果相同（FR-13）。
- 找不到 `software.xml` 或檔案損毀時，工具會顯示原因和預期的目錄結構，然後結束（FR-14）。

### 從網路磁碟執行

- 用 UNC 路徑（`\\server\share\Helper\helper.exe`），或先複製到本機。對應的磁碟機代號（例如 `Z:`）是登入時建立的，提權後的程式可能看不到它。
- 系統設定任務的 .cmd 會先複製到本機的暫存資料夾再執行（`cmd.exe` 不接受網路路徑作為工作目錄，DD16）。
- 軟體項目會先複製到本機（`copyFirst`，見第 4 節），所以複製時間取決於網路速度。

## 3. 權限：只讓系統管理員寫入（NFR-07）

**為什麼**：工具以系統管理員權限執行資源資料夾裡的安裝檔和 .cmd。能寫入資源資料夾（或替換 `helper.exe`）的人，就能讓自己的程式以系統管理員權限執行。

**要保護的範圍**：`helper.exe` 和整個資源資料夾。最簡單的做法是把兩者放在同一個專用資料夾（例如 `D:\Helper\`），只設定這一個資料夾。

### 本機或檔案伺服器上的資料夾（NTFS）

以系統管理員身分開啟命令提示字元：

```bat
icacls "D:\Helper" /inheritance:r /grant:r *S-1-5-32-544:(OI)(CI)F *S-1-5-18:(OI)(CI)F *S-1-5-32-545:(OI)(CI)RX
```

| SID | 群組 | 權限 |
|---|---|---|
| `S-1-5-32-544` | Administrators | 完整控制 |
| `S-1-5-18` | SYSTEM | 完整控制 |
| `S-1-5-32-545` | Users | 讀取與執行 |

- 用 SID 指定群組，不受 Windows 語系影響。
- `/inheritance:r` 會移除這個資料夾從上層繼承來的權限，**只對 Helper 專用的資料夾執行**，不要對整顆磁碟或使用者資料夾執行。
- 確認：`icacls "D:\Helper"` 只列出上面三個群組；用一般使用者帳號試著在資料夾裡建立檔案，應該會被拒絕。

### 共用資料夾

除了上面的 NTFS 權限，共用權限也只給一般使用者「讀取」，只有維護的人能「變更」。

### 隨身碟

FAT32、exFAT 格式的隨身碟沒有檔案權限，任何人都能修改內容。只在隨身碟一直由維護的人保管時使用；或改用唯讀的方式發佈，例如從受保護的共用資料夾複製。

### 工具自己設定的權限

執行時的暫存資料夾（第 4 節），由工具自己設定為只有 Administrators 與 SYSTEM 可以寫入，不需要另外設定。

## 4. 暫存資料夾與空間（FR-46～FR-48）

**流程**：按「開始執行」後，工具先把勾選的軟體子資料夾複製到「下載」資料夾裡的暫存資料夾，全部執行完再刪除。

```
<下載>\Helper_20261022_153000\    ← 執行完自動刪除
```

- 「下載」資料夾以 Windows 的已知資料夾取得，使用者把它移到其他磁碟時也正確（DD13）。
- 系統設定任務的 .cmd 也一律先複製（檔案很小）。
- `copyFirst="false"` 的軟體不複製，直接從資源資料夾執行，見 [`MAINTENANCE.md`](MAINTENANCE.md) 第 3 節。
- 安裝程式結束後，它啟動的程式可能還在使用暫存檔，所以全部項目結束後才刪除（DD15）。被佔用的檔案最多重試 60 秒；仍然刪不掉時會列在完成對話框與日誌，下一輪執行時再刪除。
- 工具只刪除自己建立的暫存資料夾（名稱以 `Helper_` 開頭、帶有標記檔 `.helper_staging`），不會刪除其他檔案。3.0.0、3.0.1 留下的暫存資料夾（`Hpler_` 開頭、帶有 `.hpler_staging`）也會被刪除。

**需要的空間**：勾選的軟體子資料夾大小加總，再加 1 GB 餘裕。空間不夠時，工具不執行任何項目，並顯示需要與可用的空間（FR-47）。

以 2026-10-21 的真實資料為例（大小以檔案總管顯示的單位計算）：

| 軟體 | 大小 | 先複製 |
|---|---|---|
| 3DMark | 12.8 GB | 是 |
| PCMark10 | 4.2 GB | 是 |
| 其他 16 項 | 合計約 1.2 GB | 是 |
| SampleDeskTool | 28.6 GB | 否（`copyFirst="false"`） |
| SampleDeskFiles | 0.3 GB | 否（`copyFirst="false"`） |

全選時約需複製 18.2 GB，加上餘裕，「下載」資料夾所在的磁碟至少要有 **約 20 GB** 的可用空間。只勾選幾個小工具時，需要的空間很少。

**時間**：複製時間取決於資源資料夾所在位置（隨身碟、網路磁碟）的讀取速度，大型軟體可能需要數分鐘。

## 5. 日誌

- 位置：`<桌面>\QT_TOOL_LOGS\Helper_<軟體安裝|系統設定>_<日期時間>.log`，每輪執行一個檔案。3.0.1 以前的日誌是 `Hpler_` 開頭，留在原處。
- 桌面以 Windows 的已知資料夾取得：開啟 OneDrive 備份桌面時，日誌在 OneDrive 的桌面裡（DD10）。
- 內容包含每個項目的完整命令列、結束碼、完整輸出、複製與刪除的結果。回報問題時，請附上日誌。
- 介面上的「日誌資料夾」按鈕會開啟這個資料夾。

## 6. 升級

### 從 3.0.0、3.0.1 升級

只要換掉 `helper.exe`：設定檔、資源資料夾、權限都不用改。3.0.2 起產品名稱從誤寫的「Hpler」更正為「Helper」，看得到的差異：

| 項目 | 3.0.1 以前 | 3.0.2 起 |
|---|---|---|
| 視窗標題、對話框、執行檔內容的產品名稱 | Hpler | Helper |
| 日誌檔名 | `Hpler_<模式>_<日期時間>.log` | `Helper_<模式>_<日期時間>.log`。舊的日誌留在原處 |
| 暫存資料夾 | `<下載>\Hpler_<日期時間>\` | `<下載>\Helper_<日期時間>\`。舊版異常結束留下的會在下一輪自動刪除 |
| 資源資料夾裡的視窗圖示 | `hpler_icon.ico` | `helper_icon.ico`。沒有時使用 `hpler_icon.ico`，所以不用改名 |

有問題時換回原本的 `helper.exe` 即可。

### 從 2.0 升級

1. **轉換設定檔**：在有原始碼的電腦上執行轉換工具，見 [`MAINTENANCE.md`](MAINTENANCE.md) 第 6 節。
   ```bat
   python tools\ini2xml.py <2.0 的資源資料夾> <輸出資料夾> --no-copy-first <會自己複製到桌面的軟體 id>
   ```
2. **逐項確認轉換報告**（輸出資料夾裡的 `ini2xml_report.txt`）。
3. **放進資源資料夾**：把輸出的 `software.xml`、`system_tasks.xml`、兩個 XSD、`tasks\` 放進資源資料夾，和各軟體子資料夾放在一起。舊的 `config.ini`、`system_optimizations.ini` 3.0 不會讀取，可以保留給 2.0 的執行檔使用。
4. **把 2.0 的執行檔換成 `helper.exe`**。
5. **在測試機上驗證**：每個 .cmd 都以系統管理員身分執行一次；每個軟體都安裝一次。
6. **保留 2.0 的執行檔**：3.0 有問題時，可以退回 2.0（2.0 只讀 INI，兩種設定檔可以並存）。

## 7. 常見問題

| 狀況 | 原因與處理 |
|---|---|
| 雙擊後跳出 UAC，按「否」之後什麼都沒有 | 正常：工具需要系統管理員權限，按「否」就不啟動（FR-02） |
| 「Helper 無法啟動」，列出預期的目錄結構 | 找不到 `software.xml`，或檔案不是合法的 XML／不是 UTF-8。依訊息修正 |
| 啟動時跳出問題清單 | 設定檔有錯誤或提醒；有問題的項目不會顯示在清單上。用「複製」按鈕把內容回報給維護的人，見 [`MAINTENANCE.md`](MAINTENANCE.md) 第 5 節 |
| 「空間不足」 | 「下載」資料夾所在的磁碟空間不夠，見第 4 節。清出空間，或少勾選幾個大型軟體 |
| 某個軟體顯示「複製失敗」 | 複製到暫存資料夾時出錯（例如網路中斷、檔案被鎖定）。其他項目照常執行；原因在日誌 |
| 完成對話框列出「刪不掉的檔案」 | 有程式還在使用暫存檔。下一輪執行時會再刪除；也可以重新開機後再執行一次工具 |
| 系統設定分頁顯示「系統設定無法使用」 | 找不到 `system_tasks.xml`，或檔案有錯誤；原因顯示在分頁上，也在問題清單裡 |
