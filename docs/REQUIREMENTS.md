## 1. 目的與範圍

Helper 是 Windows 上的軟體安裝自動化與系統設定工具：使用者勾選要安裝的軟體或要套用的系統設定，工具會依序自動執行，並記錄結果。

本文件定義接下來各版本**必須滿足的需求**，包括：

- 要**保留**的現有功能（2.0）
- 2.0.1：執行檔移到資源資料夾外面
- 2.0.2：小修
- 3.0.0：設定檔改成 XML、系統設定任務改成 .cmd 腳本

怎麼實作、什麼時候做，會在需求定版後另外寫成設計文件與開發規劃。

---

## 2. 使用者與使用情境

| 角色 | 做什麼 |
|---|---|
| 使用者 | 在 Windows 電腦上批次安裝測試軟體、套用系統設定 |
| 維護者 | 新增或修改軟體清單與系統設定任務 |
| 開發者 | 修改程式、打包、發行 |

**典型流程：** 把工具複製到目標電腦 → 執行 `Helper.exe` → 勾選項目 → 按「開始執行」 → 看完成對話框與日誌。

## 3. 名詞

| 名詞 | 定義 |
|---|---|
| 資源資料夾 | 放設定檔、圖示與各軟體子資料夾的資料夾（`Helper\` 或 `helper_software\`） |
| 軟體項目 | 軟體清單中的一筆，對應一個安裝檔與它的參數 |
| 系統設定任務 | 系統設定清單中的一筆，對應一組系統指令（3.0 起為一個 .cmd 檔） |
| 問題清單 | 3.0 起，啟動時列出所有有問題、被略過的設定項目 |
